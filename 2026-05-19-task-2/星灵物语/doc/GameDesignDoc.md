## 1. 游戏概述

**星灵物语** 是一款结合「连连看/三消」与「回合制角色战斗」的二次元微信小游戏。玩家通过消除盘面上5种颜色的宝石，积攒能量并召唤对应属性的美少女角色释放技能，击败关卡中的敌人。

### 1.1 核心一句话
> **消除宝石 → 积攒能量 → 释放美少女技能 → 击败敌人**

### 1.2 游戏时长定位
| 维度 | 数值 | 说明 |
|------|------|------|
| 单局时长 | 1-3分钟 | 限步挑战，节奏轻快 |
| 每日活跃 | 10-20分钟 | 日常+体力消耗 |
| 单次session | 5-8分钟 | 碎片化时间游玩 |

## 2. 设计支柱

1. **消除的爽快感** — 连击、特效、屏幕震动，每一次消除都有即刻正反馈
2. **角色的陪伴感** — 每个角色有独立的Live2D立绘、语音、技能动画，养成带来情感连结
3. **策略的深度** — 不同关卡需要搭配不同属性队伍，消除路线影响战局走向
4. **社交的轻竞争** — 好友战力榜、关卡排名形成轻度竞技，不强制组队

## 3. 核心玩法

### 3.1 棋盘规格
- **8×8** 标准棋盘，5种颜色宝石
- 每种颜色对应一种角色属性

### 3.2 消除规则 (连线消除)
```
[A] 玩家点击第一个宝石开始连线
[B] 向相邻(上下左右)方向滑动，连接同色宝石
[C] 连接 ≥ 5 个同色宝石形成消除链
[D] 消除的宝石数量决定：
    - 基础能量值（消除数 × 2）
    - 技能伤害倍率（消除数 × 攻击力 × 0.2）
```

**关键参数**:
| 参数 | 值 | 说明 |
|------|------|------|
| 最小消除数 | 5 | 低于5个不可消除 |
| 最大连接数 | 无上限 | 但受棋盘限制和步数限制 |
| 消除得分 | 消除数 × 10 + 额外连击奖励 |
| 能量获取 | 消除数 × 2 | 每个消除宝石提供2点能量 |
| 额外奖励 | 8连以上额外+50%能量 | 鼓励长链消除 |

### 3.3 步数系统
- 每局有限步数（默认20步）
- 每步 = 完成一次消除（或主动pass）
- 步数用完 → 强制结算
- 特殊道具可增加步数

### 3.4 胜利条件
- **三星条件**:
  - ⭐ 击败敌人（通关）
  - ⭐⭐ 剩余步数 ≥ 5
  - ⭐⭐⭐ 剩余步数 ≥ 10
- 未击败敌人 = 失败，消耗1点体力

## 5. 能量与技能系统

### 5.1 能量机制
- 每个角色有独立的**能量槽**（上限100点）
- 消除对应颜色宝石 → 对应角色获得能量
- 能量槽满 → 角色头像高亮 → 玩家可点击释放大招

```
EnergyGain = GemCount × 2
If GemCount ≥ 8: EnergyGain × 1.5  // 长链奖励
```

### 5.2 技能体系
每个角色拥有两个技能：

**① 普通技能 (小技能)** — 能量消耗30
- 自动释放（能量达到30时自动触发）或手动选择
- 效果：单体攻击/治疗/增益
- CD：每2回合可触发1次

**② 终极技能 (大招)** — 能量消耗100
- 手动点击释放，全屏动画特效
- 效果：强力群体攻击/全体回复/强力buff
- 释放后清空能量

## 6. 关卡系统

### 6.1 关卡结构
```
章节 1 (1-1 ~ 1-10) → 章节 Boss (1-10)
章节 2 (2-1 ~ 2-10) → 章节 Boss (2-10)
...
章节 8 (8-1 ~ 8-10) → 最终 Boss
```

### 6.2 关卡难度曲线
| 章节 | 敌人HP | 宝石颜色分布 | 步数 | 特殊规则 |
|------|--------|-------------|------|----------|
| 1-1 ~ 1-5 | 100-200 | 均衡 | 25 | 新手引导 |
| 1-6 ~ 1-10 | 200-400 | 均衡+Boss色偏多 | 22 | 导入Boss机制 |
| 2-1 ~ 2-5 | 300-500 | 某色减少 | 22 | — |
| ... | 逐步提升 | 复杂组合 | 递减至18 | 新增障碍物/特殊宝石 |
| 8-10 | 3000 | 极端分布 | 15 | 多阶段Boss |

### 6.3 关卡特殊元素
| 名称 | 效果 | 首次出现 |
|------|------|----------|
| 冰封宝石 | 消除1次才可激活 | 第2章 |
| 暗黑宝石 | 消除后扣除少量能量 | 第3章 |
| 炸弹宝石 | 消除后炸毁周围3x3 | 第4章 |
| 彩虹宝石 | 可当作任意颜色 | 第5章 |
| 锁定宝石 | 需消除2次才能消除 | 第6章 |

## 8. 养成系统 (轻度)

### 8.1 角色等级
```
Lv.1 → Lv.10 (满级)
升级消耗: 经验药水 + 金币
每级提升: 攻击+8%, HP+6%
```

| 等级 | 所需经验 | 累计经验 |
|------|---------|---------|
| 1→2 | 100 | 100 |
| 2→3 | 200 | 300 |
| ... | ... | ... |
| 9→10 | 900 | 4500 |

### 8.2 角色突破
```
消耗同角色碎片 ×5 + 金币 ×5000
突破后: 等级上限+5, 解锁新技能效果
最多突破3次 (Lv.10 → 突破1 → Lv.15 → 突破2 → Lv.20 → 突破3 → Lv.25)
```

### 8.3 技能升级
```
消耗: 技能书 + 金币
每级提升: 技能伤害+5%
上限: Lv.5
```

### 8.4 好感度系统
| 好感等级 | 所需好感 | 解锁内容 |
|----------|---------|----------|
| Lv.1 | 0 | 基础 |
| Lv.2 | 100 | 角色语音2 |
| Lv.3 | 300 | 背景故事 |
| Lv.4 | 600 | 角色语音3 |
| Lv.5 | 1000 | 专属头像框 |

## 10. 经济系统

### 10.1 货币体系
| 货币 | 图标 | 获取方式 | 用途 |
|------|------|----------|------|
| 金币 | 🪙 | 关卡掉落、分解 | 升级、突破 |
| 星钻 | 💎 | 付费、关卡奖励、分享 | 抽卡、买体力 |

### 10.2 经济流动
```
关卡 → 金币(主要) + 角色经验(少量)

     → 买体力 (60星钻=120体力)
     → 买金币 (60星钻=10000金币)
```

## 12. 技术架构

### 12.1 Cocos Creator 组件结构
```
GameManager (单例)
├── EventManager (事件总线)
├── AudioManager (音频管理)
├── SaveManager (存档/微信云存储)
├── BoardManager (棋盘逻辑)
│   └── GemController (单个宝石)
├── MatchLogic (消除算法)
├── BattleController (战斗流程)
├── SkillController (技能释放)
├── UIManager (UI栈管理)
└── [System Singletons]
    ├── LevelSystem
    ├── GachaSystem
    ├── CultivationSystem
    └── SocialSystem
```

### 12.2 数据流
```
用户输入 → BoardManager → MatchLogic → 消除判定
    → BattleController → 伤害计算 → 敌人状态更新
    → SkillController → 能量检查 → 角色技能触发
    → UIManager → 视觉反馈 → 等待下一步输入
```

### 12.3 存档系统
- 使用微信小游戏 `wx.setStorageSync` / `wx.getStorageSync`
- 云存档：`wx.cloud.database()` 保存关键数据
- 存档频率：每场战斗结束、抽卡、养成操作后立即保存
