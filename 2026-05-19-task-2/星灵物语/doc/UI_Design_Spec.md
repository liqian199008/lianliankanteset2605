# 星灵物语 — UI设计规范 v1.0

## 1. 设计语言

### 1.1 风格定位
```
风格: 清新治愈系二次元
参考: 原神Q版角色风格
关键词: 马卡龙色系、柔和光影、圆角、毛玻璃效果
氛围: 温暖、梦幻、治愈
```

### 1.2 色彩体系
```
主要色板:
  🌤 天空蓝    #7EC8E3 - 主色调，用于导航栏、按钮主色
  🌸 樱花粉    #FFB7C5 - 辅色调，用于强调、装饰
  🌟 星辉金    #FFD700 - 稀有度色，用于SSR、高亮
  🤍 暖白      #FFF8F0 - 背景底色
  🌙 月白      #F0F4F8 - 卡片底色
  
功能色板:
  🔴 危险      #FF6B6B - 警告、伤害数字
  🟢 成功      #51CF66 - 治疗、升级
  🟡 警告      #FFD43B - 提示
  🔵 信息      #339AF0 - 普通信息

文字色阶:
  #4A4A4A - 主标题/正文
  #9B9B9B - 次要文字/提示
  #CCCCCC - 禁用/占位
```

### 1.3 字体规范
```
主字体:   Noto Sans SC / Source Han Sans
标题:     Bold, 36-48px
按钮:     Medium, 28-32px
正文:     Regular, 24-26px
小字:     Regular, 18-20px
```

### 1.4 间距网格
```
基础间距: 4px
UI间距:   8px → 16px → 24px → 32px → 48px → 64px
内容边距: 24px (左右), 32px (上下)
卡片圆角: 16px (大卡片), 8px (小元素)
```

## 3. 动效规范

### 3.1 过渡动画
```
面板弹出:   scale 0.8→1.0, opacity 0→1, easing: backOut, 200ms
面板关闭:   scale 1.0→0.8, opacity 1→0, easing: linear, 150ms
场景切换:   cross-fade, 300ms
按钮点击:   scale 1.0→0.9→1.0, 100ms
```

### 3.2 游戏内动效
```
消除:  缩放消失 0.15s + 粒子飞散 0.3s
下落:  bounceOut 0.3s
连击:  大字弹出 scale 0.5→1.2→1.0 0.5s
大招:  全屏白色闪光 0.1s + 震动 0.3s
能量满:  脉冲光晕 0.5s loop
胜利:  慢动作 + 金色粒子 1.5s
```

### 3.3 粒子效果
```
消除粒子:  8-12个, 彩色, 随机方向, 0.3s消散
SSR抽卡:  80个金色粒子, 全屏爆发, 2.0s
升级:  蓝色粒子上升, 0.8s
连击:  冲击波环扩散, 0.4s
```

## 5. 适配规范

### 5.1 分辨率适配
```
设计尺寸: 750 × 1334 (iPhone 6/7/8)
适配策略: SHOW_ALL
安全区域: 上下各留 44px 边距
```

### 5.2 微信小游戏特殊适配
```
刘海屏: 顶部状态栏使用 wx.getSystemInfo 获取 safeArea
状态栏: 半透明毛玻璃效果, 高度 44px
底部横条: 导航栏向上偏移 34px
字体缩放: 禁用微信字体缩放 (设置 textExtraInfo)
```
